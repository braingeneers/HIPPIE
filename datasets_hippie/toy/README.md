# `toy` — minimal smoke-test dataset

20 synthetic neurons (10 fake-PV, 10 fake-SOM) in the canonical HIPPIE
CSV layout. Generated by `scripts/generate_toy_dataset.py` from a fixed
random seed (42). Used by:

- `examples/extract_embeddings.py --datasets toy ...`
- `hippie-cli validate-data datasets_hippie/toy`
- `tests/test_dataset_schema.py`, `tests/test_inference.py`,
  `tests/test_cli.py`

These spike statistics are not biologically meaningful — they exist
only so a new user can run the full HIPPIE pipeline end-to-end without
downloading anything, and so CI can smoke-test the loader, the
preprocessing, and the inference API.

## Schema

| File | Shape | Notes |
|---|---|---|
| `waveforms.csv` | 20 × 50 | trough at sample 20 (canonical layout) |
| `isi_dist.csv`  | 20 × 100 | 1 ms bins, range 0–100 ms |
| `acg.csv`       | 20 × 201 | 1 ms bins, range −100…+100 ms, center bin = 0 |
| `labels.csv`    | 20 × 1  | column name "label"; values "PV" or "SOM" |
